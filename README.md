# Пик-контроллер

Маленькое Windows-приложение в трее: по клику на иконку всплывает окошко с текущим
статусом «пик / не пик» и ценами для **DeepSeek API** и **GLM Coding Plan (Z.ai)**.
Данные приложение само сканирует с официальных страниц документации (по умолчанию
каждый час), показывает время последнего обновления и понятную ошибку, если сайт
изменился и парсер перестал работать. Интерфейс — на русском. Работает полностью
локально, никуда ничего не отправляет.

## Запуск

Первый раз: двойной клик по **`setup.bat`** — он создаст рядом папку `.venv` на Python 3.12
и поставит пакеты `PySide6`, `requests`, `tzdata` (больше ничего ставить не нужно).

Дальше — двойной клик по **`start.bat`**; приложение сворачивается в трей (иконка — цветной кружок):

- **зелёная** — у обоих провайдеров сейчас не-пик;
- **красная** — хотя бы у одного идёт пик;
- **жёлтая** — не удалось обновить данные (сайт изменился или недоступен).

Левый клик по иконке — показать окошко, правый — меню (Показать / Обновить сейчас /
Автозапуск с Windows / Выход).

Окошко без рамок и кнопок Windows, скруглённое, поверх всех окон. Исчезает само:
когда курсор уходит из него, когда вы кликаете в любое другое место или по `Esc`.
Позиция — над треем, у места клика.

## Что показывается

- **GLM Coding Plan**: пилюля «ПИК/не пик», пиковое окно в вашем местном времени
  (будни 14:00–18:00 UTC+8), лимиты выбранного тарифа (Lite / Pro / Max / Team Std /
  Team Prem), коэффициенты списания по моделям, применяемый множитель списания
  (×1.0 пик / ×0.5 не-пик) подсвечен синим.
- **DeepSeek API**: модели `deepseek-flash` и `deepseek-v4-pro`, по три строки цен
  (вход с кэшем / вход без кэша / выход) в двух колонках — не-пик и пик; применяемая
  сейчас цена подсвечена синим. Пиковые окна: будни 01:00–04:00 и 06:00–10:00 UTC,
  кроме китайских государственных праздников.
- Подсказка в строке пика объясняет причину не-пика: «выходной», «китайский праздник»
  или «вне пиковых часов».

## Откуда данные и как они проверяются

Источники — только официальные страницы документации (их markdown-версии, без браузера):

| Источник | Страница |
|---|---|
| DeepSeek | `api-docs.deepseek.com/quick_start/pricing.md` + `updates.md` (hash) |
| GLM (Z.ai) | `docs.z.ai/devpack/overview.md` + `devpack/notice/usage-revision.md` (кросс-чек) |

На каждом обновлении выполняются sanity-проверки: состав моделей, правило «не-пик =
пик/2» у DeepSeek, пропорции кредитов у GLM, наличие пиковых часов в тексте, разумные
границы цен. Последний корректный снимок хранится в `data/cache.json` (last known
good). Если сайт сломался — оранжевый баннер в окошке, жёлтая иконка в трее, а данные
остаются из кэша с пометкой времени.

Сеть ограничена по времени: на источник отводится ~10 с (внутри — до трёх попыток,
потому что docs.z.ai рвёт TLS при частых запросах). Недоступный сайт не «подвешивает»
обновление: цикл укладывается в ~30 с и отдаёт кэш.

## Настройки — `config.json`

- `refresh_interval_minutes` — период фоновой проверки (по умолчанию 60);
- `ui_transparent` — экспериментальная прозрачность окна (по умолчанию `false`):
  на многих машинах WebView2 не поддерживает прозрачный фон, и вокруг окошка
  виден тёмный прямоугольник; при `false` окно непрозрачное с системным скруглением;
- `glm_prices` — цены тарифов (на официальной странице их нет в машинном виде; Lite —
  официальная, Pro/Max — по данным на ноябрь 2026, помечены «≈, не офиц.»);
- `glm_static_plans` — лимиты Team-тарифов.

Календарь китайских праздников для DeepSeek — `app/core/holidays_cn.json`
(ориентировочные даты; раз в год стоит сверять с официальными анонсами КНР).

## Для разработки

- Тесты парсеров и расписаний на зафиксированных копиях реальных страниц:
  `.venv\Scripts\python.exe tests\test_parsers.py`
- Проверка сети и всего конвейера без окна: `.venv\Scripts\python.exe app\main.py --selftest`
- Журнал: `data/app.log`, кэш: `data/cache.json`.
- Если сайт изменился: обновите соответствующий парсер в `app/sources/`,
  скачайте новую копию страницы в `tests/fixtures/` и дополните тесты.

## Технологии

Python 3.12 · PySide6 (Qt6: трей, окно, WebEngine/Chromium) · requests. Интерфейс
приложения раздаётся собственным локальным HTTP-сервером (только 127.0.0.1).
Публиковаться не предполагается — приложение для локального использования.

> Важно: нужен именно Python **3.12** (в `.venv` он и лежит; `start.bat` сам находит
> интерпретатор, а без `.venv` пробует `pyw -3.12`). На Python 3.14 связка
> pywebview/pythonnet нестабильна — поэтому используется Qt-версия.
